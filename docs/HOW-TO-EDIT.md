# دليل التعديل — إزاي تعدّل إيه فين

## القاعدة الذهبية

> **`assets/app.js` و `assets/app.css` ملفين build — ما تعدّلش فيهم يدوي.**
> **كل كلمة في الموقع** (مش بس الكلام الأساسي) موجودة في **`config.js`**.
> عدّل → `Ctrl+F5`. خلاص.

---

### ⚠️ قواعد مهمة في `config.js`

- لو عايز ترجّع قيمة لحالها الأصلية، **امسح السطر كله** — مش بس النص جوه.
- `anniversaryDate` لازم يفضل `new Date("2026-01-12T00:00:00")` — بينفعش تكتبه نص عادي.
- `envelope.message` و `ending.message` جوّاهم backticks `` ` `` — سيبها زي ما هي.
- **المصفوفات بتتقفل بالكامل**: `gallery` / `milestones.events` / `ui.story` / `ui.timerNote` / `ui.timeUnits`.
  لو عدّلت عنصر واحد، لازم تسيب باقي العناصر تحته.(engine بيمسح القديم ويرسم الجديد).
- **سيب الفاصلة `,`** في آخر كل عنصر جوّه أي قائمة.
- مفيش **دوال** مسموحة — `config.js` بيتحول لنص جوه الكود.
- لو عدّلت حاجة ومش ظهرت → `Ctrl + F5` (صدّر الكاش).

### ⚠️ ملاحظة مهمة: `ui.story` مش ظاهر دلوقتي

مشهد اللعبة المتحرك في الصفحة الرئيسية **واقف على أول حالة** (`idle`) — يعني
بتشوف العنوان والزرار، بس **الشخصية الكلامدة مش بتظهر**.

السبب إن الـ build جاي من غير حالة تشغيل (state machine) بتشغّل المشهد —
الـ setter جوه المكوّن **مش متنادى خالص**. ده وضع موجود في الملف الأصلي من
قبل ما نعدل عليه، مش من تعديلاتنا.

**يعني:** الكلام في `ui.story` **متوصّل وجاهز**، بس مش بيظهر لحد ما المشهد
يتحرّك. لو عايزه يظهر، ده **تعديل بنيوي** (محتاج نضيف `useEffect` بتشغّل
الحالات) — شوف القسم ١٢. اختبره بـ `npm run verify` (بيتأكد إن المفاتيح
موجودة) حتى لو مش ظاهر.

اللعبة **اللي بتشتغل فعلاً** هي `game.html` (افتحيها من الزرار).

## ٢. الصور

1. حط الصورة في `images/`.
2. في `config.js` تحت `gallery`:
```js
gallery: [
  { src: "./images/sara-1.jpg", caption: "من غير ما تحاول 🤍" },
  { src: "./images/sara-5.jpg", caption: "الجديدة" },     // ← السطر الجديد
  { src: "./images/sara-2.jpg", caption: "هدوء من نوع تاني" },
],
```
- المسار **نسبي على `./`** ودايمًا `./images/...`
- الصور **طولية (portrait) تمام** — المعرض بيستخدم `object-contain` وبيظبط الطول أوتوماتيك (حد أقصى 60vh).
- عدد نقاط التنقل تحت المعرض بيتظبط **لوحده** حسب عدد الصور.
- لو حذفت صورة، **امسح سطرها** — مش بس خليه فاضي.

## ٣. الصوت

المسار في `config.js`:
```js
audioUrl: "./media/audio/khalini.mp3",
```
حط الملف الجديد في `media/audio/` وغيّر المسار.

⚠️ المتصفح بيمنع تشغيل الصوت قبل أي تفاعل من المستخدم. ده سلوك طبيعي ومقصود (مش bug).

### الحجم — دي أكبر نقطة في الموقع دلوقتي

الأغنية **7.7 ميجا** من إجمالي الموقع 10.3 ميجا، ومُرمّزة بـ **320 kbps**
(أعلى جودة تخزين، ومش-quality دي محتاجة أصلاً). اتشالبيها:
```bash
npm i -g ffmpeg-cli     # أو نزّل ffmpeg من ffmpeg.org
ffmpeg -i media/audio/khalini.mp3 -vn -ac 2 -b:a 128k media/audio/khalini-128.mp3
```
- القياسات الفعلية: `@192` = 4.59MB · `@128` = **3.06MB** · `@96` = 2.30MB
- يعني الموقع كله هينزل من **10.3MB → 5.7MB** لو رحت 128k.
- فرق الصوت بين 320k و128k **مش محسوس** في الخلفية. جرّب الأول لو عايز أضمن حاجة.
- بعد ما تعمل الملف الجديد: `Move-Item media/audio/khalini-128.mp3 media/audio/khalini.mp3` (أو غيّر المسار في `config.js`).

عايز تتأكد من أي ملف؟
```bash
node tools/probe-audio.mjs [المسار]
```

### تحميل الصوت بيحترم_connection المستخدم

مفيش `preload` ثابت للأغنية في `index.html`. بدله سكربت صغير بيحملها بس على
اتصال كويس، وبيتخطّى لو:
- المستخدم فعّل **Save Data** (وضع توفير الداتا في الموبايل)، أو
- الاتصال `2g` / `3g`.

السبب: الأغنية **مش هتتلعب** غير لما هي تدوس على زرار الموسيقى، يعني بعد ما
تعدّي على تسجيل الدخول وتقرا الرسالة. إننا نحمّل 7.7MB قبل ما تشوفي حاجة =
استهلاك داتا من غير فايدة.

لو عايزها محمّلة دايمًا (نفسك على واي فاي بس): احذف شرط `return` في السكربت
داخل `index.html`.

## ٧. صفحة اللعبة (`game.html`)

صفحة مستقلة تمامًا — **HTML + CSS + JS كله جوّه الملف**.
- CSS في `<style>` في أول الملف
- HTML في `<body>` (البورد بتاع النجوم)
- JS في آخر الملف `<script>`
- مفيش صور ولا ملفات خارجية.
- **مش متأثرة بـ `config.js`** — لو عايز نفس النصوص، انسخها يدوي.
- الرسالة الأخيرة بتظهر لما توصّلي النجوم ببعضها.

### تعديل نجوم اللعبة

النجوم مكتوبة في `<body>` جوّه `#board`. **ترتيبهم في الملف هو ترتيب التوصيل** —
يعني النجمة الأولى في الكود هي اللي بتبدأي منها:

```html
<div class="node" style="top:21.4126%;left:10.5424%">
  <div class="core">1</div><div class="halo"></div>
</div>
```

- `top` و `left` **نِسب مئوية** من حجم البورد، فالنجوم بتظبط على أي شاشة.
  لازم يكونوا بين 0 و 100.
- الرقم جوه `.core` بيتكتب تلقائيًا من ترتيب النجمة في الملف — سيبه زي ما هو.
- `.next` بتتحط على النجمة الجاية، و `done` على اللي خلصت. لو غيرت الترتيب، الشكل
  كله هيتغيّر.
- لو زوّدت أو شلت نجوم، عديّاد `#progress` (`٠ من ٨`) بيتحسب لوحده — سيبه.

**بعد ما تلمس الترتيب أو الأرقام، شغّل:**
```bash
npm run check:game
```
بيتأكد إن كل نجمة عندها 위치 جوّه البورد وإن السكربت بيترجم.

## ٨. بعد أي تعديل على الملفات الثابتة

```bash

```

## ١٠. الأدوات (كلها في `tools/`)

| الأمر | بيعمل إيه |
|---|---|
| `npm test` | الفحص كله: syntax + تدقيق المحتوى +隅证 الـ config + تشغيل كامل |
| `npm run audit` | **بيأكد** إن مفيش كلام قديم ولا كلام عربي متخبّى في الكود، وإن `config.js` والـ bundle متطابقين |
| `npm run strings` | بيطبع كل النصوص العربية اللي في الكود (المفروض: **صفر**) |
| `npm run verify` | بيأكد إن دمج الـ config شغال صح (Date / مصفوفات /subsection) |
| `npm run test:boot` | بيفتح الموقع في DOM حقيقي ويمشي في الرحلة كلها |
| `npm run check:game` | فحوص ثابتة للعبة: هندسة الموبايل + ترجمة السكربت + ترتيب النجوم |
| `npm run test:negation` | اختبار قاعدة «الاعتراف مقابل نفي الاعتراف» |
| `npm run patch` | بيخلي أي نص جديد في الكود قابل للتعديل من `config.js` |
| `npm run patch:structure` | إصلاحات سلوك في الكود المصغّر (atomically — لو patch فشل مش بيكتب) |
| `npm run sync:bundle` | بيولّد نسخة القيم الافتراضية جوه الـ bundle من `config.js` |
| `npm run icons` | تجديد أيقونات التطبيق |
| `npm run version:bump` | رفع نسخة الـ cache |
| `npm run pages:on` | يفعّل GitHub Pages من السيرفر من غير ما تفتح متصفح |

**ترتيب مهم لو عدّلت `config.js`:**
```bash
npm run sync:bundle    # عشان القيم الافتراضية جوه الكود تبقى زيها
npm test               # والتأكد
```

## ١١. لو جابلك خطأ

| العرض | السبب المحتمل |
|---|---|
| الصفحة بيضا | خطأ JS — `npm test` هيقولك فين |
| النص مش بيتغيّر | cache قديم → `Ctrl+F5` |
| `audit` بيقولك `Dt.ui.xyz` مفقود | نسيت تضيف المفتاح في `config.js` — شغّل `npm run sync:bundle` بعدين `npm test` |
| الصور مش ظاهرة | مسار غلط في `config.js` (لازم `./images/...`) |
| الصوت مش شغال | المتصفح بيمنع الصوت قبل أي تفاعل — طبيعي |
| المستخدم بيشوف نسخة قديمة | نسيت `npm run version:bump` |
| التثبيت مش بيظهر | لازم **HTTPS** (أو localhost) + متصفح يدعم |
| زر التثبيت بيظهر وأنا متثبّت | جرّب من نافذة خاصة (incognito) |
| الموقع مش بيشتغل أوفلاين | شيل الـ SW من DevTools → Application → Service Workers |

## ١٢. حدود المشروع (اعرفها قبل أي تعديل كبير)

الملفات دي **ناتج build** (Vite + React + Tailwind) — الـ source الأصلي **مش موجود** في المشروع.

**يعني:**
- ✅ **كل النصوص** → `config.js` (مفيش استثناء دلوقتي).
- ✅ الصور والصوت والفيديو → ملفات + `config.js`.
- ✅ التثبيت والـ offline → `manifest.json` + `sw.js` + `install.js`.
- ✅ `game.html` → قابل للتعديل عادي (ملف واحد مستقل).
- ⚠️ **التعديلات البنيوية** (سيكسيون جديد، زرار جديد في نص الصفحة، تغيير layout، Tailwind classes جديدة) **مش ممكنة بأمان** من غير ما نعيد بناء الـ source من الصفر.
- ⚠️ أي تعديل يدوي في `assets/app.css` **هيتضيع** لو حصل build تاني.

لو محتاج أقسام جديدة فعلاً — الحل الصح هو إعادة بناء المشروع بـ React + Vite + Tailwind، مع إبقاء `config.js` + `install.js` + `sw.js` + `manifest.json` زي ما هم. قولّي وأعملها.
