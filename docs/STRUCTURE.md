## الطبقة الأولى: `config.js` (اللي بتعدّله)

كل كلمة في الموقع — من أول شاشة لآخرها — موجودة هنا. الـ bundle بياخد القيم دي
ويفظّلها على **قيمة افتراضية** جوّه نفسه، وبعدين بيعمل **دمج عميق** بين
القيمة الافتراضية و `config.js` قبل ما يرسم.

```
config.js  ──┐
             ├──►  deep merge  ──►  Dt  ──►  render
bundle  ─────┘   (shim in app.js)
```

**ليه الطبقتين؟**
- `config.js` هو اللي بتعدّله — واضح، مقروء، فيه تعليقات.
- القيمة الافتراضية جوه الـ bundle موجودة عشان **لو `config.js` فشل تحميله** الموقع
  مايقفش. من غيرها، ضيعة نت = صفحة بيضا.

**عيب الطبقتين:** بيمكن ينحرفوا عن بعض. عشان كده:
- `npm run sync:bundle` — يولّد القيمة الافتراضية من `config.js`.
- `npm run audit` — **يفشل** لو انحرفوا.

## الطبقة التانية: `assets/app.js` (اللي *مش* بتعدّله)

ملف build/minified. اتعملتله تعديلات محدودة ودائمة:

| التعديل | السبب |
|---|---|
| **shim دمج عميق** قبل `createRoot` | يخلّي `config.js` تتحكم في كل حاجة |
| `n===t.login.password` | كلمة السر بقت من `config.js` بدل ثابتة |
| `src:Dt.audioUrl||…` | مسار الصوت بقى قابل للتغيير |
| `src:l.videoUrl||…` | مسار الفيديو (كان **مش** شغال) |
| `n.map(…)` بدل `[0,1,2].map(…)` | نقاط المعرض بتتبع عدد الصور |
| **20 نص متخبي** → `Dt.ui.*` | كان فيه كلام حب مكتوب جوه الكود مش قابل للتعديل |

### أداة `patch-strings.mjs`

بتحوّل أي نص مكتوب جوه كومبوننت لـ قراءة من `Dt`:

```js
children:"وتبقى الحكاية مستمرة"        →   children:Dt.milestones.note
```

**إزاي ده ممكن أصلاً؟** `Dt` متعرَّف في مستوى الـ module، فمتاح من **أي** كومبوننت
جوه نفس الملف. عشان كده مفيش داعي نعدّل signatures متصغّرة.

الأداة **atomically** بتشتغل: لو أي patch مالوش تطابق بالظبط، **مش** بتكتب،
وبتطلع بخطأ. وبتقدر تشغّلها أكتر من مرة — اللي اتعمل بيتخطّى.

### حالة مفترضة في الـ build: مشهد المتاهة واقف

`r0` (كومبوننت مشهد المتاهة) بيبدأ بـ `useState("idle")` و**الـ setter
(`t()`) مش متنادى في أي مكان**. يعني:

- **ظاهر:** العنوان، السطر الصغير، زرار "العب المتاهة"، السطر تحتيه.
- **مش ظاهر:** الشخصية الكلامدة + الكلام في `ui.story`.

ده وضع **موجود في الملف الأصلي** — مش من تعديلاتنا. `ui.story` متوصّل
والكلام جاهز، و`npm run verify` بيتأكد إن كل مفاتيحه موجودة، لكنه محتاج
`useEffect` تشغيل (تعديل بنيوي) عشان يبقى ظاهر.

اللعبة اللي بتشتغل فعلاً هي `maze.html`.

## ليه القرارات دي

| القرار | السبب |
|---|---|
| `config.js` منفصل | التطبيق build/minified — ما ينفعش يتعدّل. فكنا المحتوى كله في ملف واحد مفهوم، ومغطّى باختبارات. |
| **الدمج العميق** بدل الاستبدال | الاستبدال الكامل كان هيمسح أي قسم ما تذكرتهوش. الدمج بيخلي `config.js` جزئي يشتغل. |
| `install.js` منفصل | ميزة التثبيت مستقلة تمامًا عن React. ملف جديد لوحده = صفر مخاطرة. |
| أسماء ثابتة `app.js` / `app.css` | الأسماء القديمة كانت هاش من Vite للـ CSS بس والـ JS لأ → تعارض. |
| `tools/bump-version.mjs` | كان في 3 أماكن لازم تتظبط → نسيانها = مستخدمين شايفين نسخة قديمة. |
| `tools/boot-test.mjs` | تعديل على build بدون اختبارات = مخاطرة. الاختبار بيعمل الرحلة كلها ويقارنها بـ `config.js`. |
| `tools/audit-content.mjs` | يمنع رجوع الكلام القديم، ويمنع انحراف الطبقتين، وبيكشف أي `Dt.*` مفتاحه ناقص. |
| `_archive/` | كان ~16MB بتاخد مساحة deploy من غير فايدة. |

## التثبيت على التليفون (PWA)

بيشتغل من غير أي كود إضافي، عن طريق:
- `manifest.json` → الاسم والأيقونات و`display: standalone`.
- `sw.js` → لازم للـ install + عشان يشتغل أوفلاين.
- `install.js` → بيعرض زر التثبيت:
  - **Android/Chrome**: بيستخدم `beforeinstallprompt` (نفس dialog الأصلي).
  - **iOS/Safari**: مفيش API، فبيعرض خطوات "المشاركة → Add to Home Screen".
  - لو متثبّت خلاص → مش بيظهر. لو Dismissed → بيختفي أسبوع.
- `images/icon-maskable-512.png` → نسخة بحدود آمنة، عشان الوش ما يتقصّش على شاشات Android الدائرية.

⚠️ **شرط أساسي:** لازم الموقع يكون على **HTTPS** (أو `localhost`) وإلا التثبيت مش هيشتغل.

### أكبر فرصة متبقية: الأغنية

الأغنية 7.66MB مرمّزة بـ **320 kbps** — دي جودة أرشيف، أعلى من اللي أي حد
بيسمعها على الموبايل محتاجه. القياسات الفعلية:

| إعادة ترميز | الحجم | الموقع كله |
|---|---|---|
|现状 320 kbps | 7.66 MB | 10.3 MB |
| 192 kbps | 4.59 MB | 7.2 MB |
| **128 kbps** | **3.06 MB** | **5.7 MB** |
| 96 kbps | 2.30 MB | 4.9 MB |

يعني **نص الموقع راجع لوحده** من تغيير سطر واحد. الأمر:
```bash
ffmpeg -i media/audio/khalini.mp3 -vn -ac 2 -b:a 128k media/audio/khalini-128.mp3
```
مفيش ffmpeg متسطّب على الجهاز دلوقتي، فمش عملتها. `npm run probe:audio`
يقيس أي ملف.

**اللي اتعمل فعلاً بدل كده:** شيل `preload` الثابت للأغنية، وحطّيت سكربت صغير
بيحمّلها بس على اتصال كويس — وبيتخطّى لو المستخدم فعّل **Save Data** أو
الاتصال 2g/3g. لأن الأغنية أصلاً مش هتتلعب غير بعد ما تدوسي زرار الموسيقى،
يعني تحميل 7.7MB قبل ما تشوفي حاجة = استهلاك داتا من غير فايدة.

## النشر (Deploy)

الموقع static — أي استضافة ملفات هتشتغل. لو GitHub Pages:
- مجلد الـ root هو اللي بينشر.
- `_archive/` مستبعد في `.gitignore` فمش هينشر.
- **بعد أي تعديل لازم** `npm run version:bump` عشان الـ cache يتحدّث.
