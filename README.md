# ساره 🤍

كلام من محمد — عن حد شافها صح، وفهمها صح، ومحترمها بجد.

موقع ثابت (HTML + React bundle + PWA). مفيش build ولا database.

## ابدأ من هنا

| عايز إيه | افتح |
|---|---|
| أعدّل نصوص / صور / إعدادات / كلمة سر | **`config.js`** ← الملف الوحيد اللي هتحتاجه |
| أعمل إيه بالظبط | [`docs/HOW-TO-EDIT.md`](docs/HOW-TO-EDIT.md) |
| أفهم الملفات والقرارات | [`docs/STRUCTURE.md`](docs/STRUCTURE.md) |

## أهم قاعدة

> **كل كلمة في الموقع موجودة في `config.js`.** مفيش استثناء.
> `assets/app.js` و `assets/app.css` ملفين **build/minified** — ما تعدّلش فيهم.
> عدّل → `Ctrl+F5`. خلاص.

## التثبيت على التليفون

بيشتغل لوحده — مفيش حاجة تعملها.
بيعرض زر تثبيت تلقائي (على iOS بيشرحلك خطوات إضافة لـ Home Screen).
**شرط واحد:** الموقع لازم يكون على **HTTPS** (أو `localhost`).

## أوامر سريعة

```bash
npm run dev            # تشغيل محلي (لا تفتح بـ file://)
npm test               # الفحص كله (40+ اختبار)
npm run audit          # مفيش كلام قديم ولا كلام عربي متخبّى في الكود
npm run strings        # يطبع أي نص عربي لسه في الكود (المفروض: صفر)
npm run sync:bundle    # بعد تعديل config.js — يحدّث القيم الافتراضية
npm run patch          # لو لقيت نص جديد متخبي في الكود
npm run icons          # تجديد أيقونات التطبيق
npm run version:bump   # بعد أي تعديل على الملفات الثابتة
```

## الحماية

كلمة السر في `config.js` — وهي **حماية واجهة بس**، مش أمان حقيقي
(أي حد يقدر يقراها من أدوات المطوّر). للموقع ده كفاية. لو محتاج أمان فعلي،
لازم سيرفر.

## النشر

مجلد الـ root هو الموقع. `_archive/` مستبعد من git ومن deploy.
بعد كل تعديل على الملفات الثابتة: **`npm run version:bump`**.
